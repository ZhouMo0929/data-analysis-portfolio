## 解决什么问题

销售数据散落在明细表里，每次看业绩都要手工筛选、汇总、做表，费时且口径不统一。
这个看板把这件事一次性做完：**打开文件，3 秒看清全局。**

## 我做了什么

- 整理 2026-01-01 至 2026-06-30 共 **120 笔**销售订单（模拟数据）
- 覆盖 **5 个区域、8 名销售员、10 款产品、5 个品类**
- 用 **592 个公式**（SUMIFS / COUNTIF / IF）跨表联动，5 处条件格式数据条，14 处合并单元格
- 4 个工作表分工明确：**看板**（可视化）／**销售明细**（原始数据）／**参数设置**（目标值可调）／**说明**（使用指引）

## 核心发现

| 指标 | 数值 |
|---|---|
| 总销售额 | ¥600,195 |
| 综合毛利率 | 24.2% |
| 订单总数 | 120 笔 |

**1. 月度波动剧烈，3 月是明显低谷**
1–2 月稳定在 ¥10 万左右，3 月骤降至 ¥44,589（环比 -52%）；随后连续三个月回升，6 月达 ¥151,098 创上半年新高，是 3 月的 3.4 倍。

**2. 华东是核心市场，西南明显掉队**
华东 ¥159,161（占 26.5%）居首；西南 ¥75,404（占 12.6%）仅为华东的 47%，是唯一不足 ¥10 万的区域。

**3. 品类高度集中，存在结构性风险**
笔记本电脑 ¥340,546，**独占 56.7%** 的销售额；加上显示器（21.1%）两项合计近 8 成。一旦笔记本行情走弱，整体业绩缺乏缓冲。

**4. 个别销售员贡献过重**
张伟个人 ¥127,479，**一人占 21.2%**，比西南整个区域的销售额还高——存在关键人依赖风险。

## 业务建议（所以呢？）

1. **排查 3 月低谷的真实原因**（春节后淡季？竞品动作？库存断档？），并复盘 5–6 月的回升动作是否可以复制。
2. **降低品类集中度**：笔记本电脑占比过高，建议在显示器、外设上做组合促销，把占比压到 45% 以下。
3. **做关键人备份**：复盘张伟的订单结构与客户来源，避免"一个人走了、一个区域塌了"。
4. **西南需要专门方案**：先弄清是渠道覆盖不足还是客单价偏低，而不是简单下指标。
